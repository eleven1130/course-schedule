# 课表解析与空闲时段计算

一个从课表算空闲时间的小工具，三个需求分三次提交（对应三次 PR）。

## 功能

| 需求 | 说明 | 命令 |
|------|------|------|
| 需求 1 | 读入课表（CSV / 手动录入），打印「本周课表」文本视图 | `python main.py show <csv>` |
| 需求 2 | 给定每日可用时间范围，算出每天的空闲时段，合并连续课程碎片 | `python main.py free <csv>` |
| 需求 3 | 输入多人课表，算出所有人的共同空闲时段，按「越长越靠前」排序 | `python main.py common <csv1> <csv2> ...` |

## 环境

- Python 3.10+（使用了 `list[int]` 等类型注解与 `from __future__ import annotations`）
- 仅依赖标准库，无需安装第三方包

## 数据格式

CSV 文件需包含表头 `name,day,start,end`：

| 字段 | 含义 | 示例 |
|------|------|------|
| name | 课程名 | 线性代数 08 |
| day | 星期几（1=周一 … 7=周日） | 2 |
| start | 开始时间 `HH:MM` | 08:00 |
| end | 结束时间 `HH:MM` | 10:30 |

`data/` 目录下附带两位同学的真实课表作为测试数据。

## 使用示例

### 需求 1：读入并打印周课表

```bash
# 从 CSV 读入
python main.py show data/zhumenghan.csv

# 手动录入（每行：课程名,星期几,开始,结束；空行结束）
python main.py show --manual
```

输出示例：

```
========================================================
本周课表
========================================================

【星期一】
  10:45 - 12:15  声乐4（流行音乐）01
  15:45 - 17:15  工科数学分析I 08
  18:00 - 20:30  大学生心理健康教育 04
...
```

### 需求 2：计算单人每天的空闲时段

```bash
python main.py free data/zhumenghan.csv
# 可自定义每日可用范围与合并间隔阈值
python main.py free data/zhumenghan.csv --day-start 08:00 --day-end 22:00 --gap 15
```

`--gap` 控制「吸收小间隔」的阈值（分钟，默认 15）。同一门课连上两节、
中间只有 10 分钟休息时，设置 `--gap >= 10` 即可把两段合并成一个占用区间，
避免在空闲时段里出现 10 分钟的碎片。

### 需求 3：计算多人共同空闲时间

```bash
python main.py common data/zhumenghan.csv data/wangtianyi.csv
```

结果按时长降序排列（越长越靠前）：

```
共同空闲时间（共 2 人）
--------------------------------------------------------
  星期日  08:00 - 22:00  (840 分钟)
  星期三  16:30 - 22:00  (330 分钟)
  星期四  17:15 - 22:00  (285 分钟)
  ...
```

## 实现要点

- **时间表示**：内部统一用「从 00:00 起的分钟数」（`int`）做区间运算，
  对外展示和 CSV 交互使用 `HH:MM` 字符串，避免浮点/字符串比较问题。
- **区间合并**（`merge_intervals`）：按开始时间排序后，若下一段的开始
  `<=` 上一段结束 + `gap_tol`，则合并。`gap_tol` 用来吸收课间休息产生的
  小间隔，消除空闲时段里的「碎片」。
- **空闲时段**（`free_time_day`）：在 `[day_start, day_end]` 内，用游标
  依次减去合并后的占用区间，得到空闲区间。
- **共同空闲**（`common_free_time`）：先对每人求每天的空闲区间，再逐日
  对所有人的区间取交集（双指针 `_intersect_two`），最后把一周的结果汇总
  并按 `end - start` 降序排序。
